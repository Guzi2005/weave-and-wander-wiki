# 资料库挂载层级

资料库按“浏览入口 → 专题 → entry”组织，不把地域、素材载体和证据图混成同一种父子关系。

1. **浏览入口**：地域／民族索引、文化专题、纹样专题、书目。一个 entry 可以从多个入口到达。
2. **专题**：汇集一组 entry，例如“摩梭人 · 服饰与手作”与“纹样 · 中国经典纹样图鉴”。专题表达策展范围，不替代具体资料。
3. **entry**：可引用的最小资料对象。套装、部件、单件物、纹样名和书目均有稳定 ID 和独立详情页。
4. **媒体与图注**：图片属于描述它的 entry。同一纹样的概览图与实例图保留在该纹样 entry 内，图注显示在对应图片下方，不因图片多而拆成伪 entry。
5. **来源关系**：纹样 entry 通过 `source.record_id` 指向书目 entry。来源可以扩展为多对多；书籍不作为纹样的 `parent_id`，以免误表示“纹样只属于此书”。`parent_id` 只用于套装与实际部件等组成关系。
6. **筛选维度**：资料类别（服装／纹样／书目等）、资料类型（套装／补充影像）和表现载体（图片／模型／视频等）各自独立，不能充当唯一目录树。没有地域关联的书目与纹样专题不显示地域地图。

本次导入的书目为 `WW-BIB-HQS-2021`；80 个纹样 entry 为 `WW-PAT-001` 至 `WW-PAT-080`。每条图例沿用原书中的图名作为图注；源书的长段正文没有复制到公开页面。媒体是独立文件，公开构建按 entry 引用复制，避免“本机有图、线上无图”。
