# 资料库服饰专题闯关

当前入口仍为 #/practice。保留资料库、导航、页眉页脚；旧五关样本工厂及其测试保留，实际入口已改为本模块。

## 界面（2026-11 精简版）

- 首页只保留标题与专题行（乌克兰服饰、摩梭人、更多挑战）：每行一个标题和一个按钮（开始/查看/完成前一专题后解锁），不再展示编号、徽章、描述、题量、历史最佳等文字，也没有导入导出、刷新题库、题库管理入口。
- 专题页只保留标题与三个按钮：重新挑战、返回专题列表、查看历史记录；历史记录默认收起，点按钮展开。
- 答题页适配一屏高度（脚本按可视区写入 --wwq-h，扣除页脚）：顶部为进度条与退出/计数，宽屏（≥900px）左右分区——左栏题干与解析、右栏单列选项加底部提交按钮，弱分隔只靠留白；窄屏从上到下依次为进度条、题目、选项（一行一个、独立圆角矩形）、提交按钮，空间不足时在容器内滚动。
- 横竖屏自适应：手机横屏（宽 560–1000px、高 ≤560px、orientation:landscape）与宽屏同样使用左右两栏，两栏各自独立滚动；同时给 body 加 wwq-playing 标记，styles.css 在该断点下收起页脚与浏览历史条并压薄页眉，为答题区让出整屏高度。手机竖屏保持垂直阅读流。桌面窗口行为不变。
- 手机竖屏答完题后，解析以底部滑出面板（.wwq-sheet，多邻国样式）呈现：结果标题、解析原文、查看相关资料与下一题按钮，面板限高 64dvh 内部可滚动；内联解析与原提交按钮在该断点下隐藏，页面不再因堆叠产生滚动。桌面与横屏仍用内联解析。
- 结算页只保留标记、标题、四项成绩与后续操作按钮；已删除口号式文案与本关要求/历史最佳说明。
- 题库工坊（独立模式）、Canvas 粒子与卡片渐变等装饰已移除；动态专题标签选择流程不变。
- 个人记录仍只保存在本浏览器（ww-quiz-learning-v1），导入导出能力保留在存储层（quiz-learning-store.js），界面入口按需求移除。

## 当前规则与题目修订

按用户后续确认，固定模块为乌克兰服饰、摩梭人，对应资料库专题 topic-ukrainian、culture-mosuo，通关率80%、75%。两关均曾通过后解锁更多挑战。按专题真实归属筛选，不从地域或“相关民族”推测档案民族身份。

每模块五道普通题，全部经过程序校验即发布，无需人工审核。元数据 method=automatic、humanReviewed=false，不声称真人审定。初版曾含内部文件名和分件编号，已修订发布版本2：题干明确中文档案名、选项使用中文服饰描述、排除文件/配方/模型/视频技术参数。

服务器 data/quiz-banks.json 追加保存固定题库版本，不覆盖旧版；默认生成请求返回现有题库，不重复调用模型。只有明确 revise=true 才新增版本。public/quiz-fixed-banks.json 保存最新两套可公开题库，不包含完整原始档案快照或个人数据。

首次加载采用最新版；已选择旧版的浏览器需点击“切换至新版题库（保留旧记录）”。旧版题目及答题记录可从详情访问。不同版本不混算逐题最佳，已取得的专题通关资格跨版本永久保留。

## 文件职责

- public/quiz-topics.js：固定专题定义、五题协议、原答题引擎适配。
- public/quiz-learning-store.js：浏览器持久化、每次挑战、逐题最佳、版本切换、导入导出。
- public/quiz-learning.js：卡片、详情/历史、真实标签选择、动态专题与管理入口。
- public/quiz-challenge.js：复用答题卡片、选项、快捷键、Canvas；宿主模式提供开始、逐题、结算与退出回调。
- lib/quiz-sources.mjs：复用资料库读模型，建立专题/地域/民族/标签索引，检索真实档案。
- lib/quiz-service.mjs：服务端硅基流动请求、模型发现、来源与可读性校验、固定版本存储。
- server.mjs：增量接入 /api/quiz/*，原有API保留。
- .env.example：无真实密钥的配置模板。
- tests/quiz-learning.test.mjs、quiz-service.test.mjs、quiz-http.test.mjs：存储/版本/出题/权限测试。
- tests/quiz-build.test.mjs：隔离公开构建验证。

## 个人记录与动态专题

localStorage 键为 ww-quiz-learning-v1，不写服务器公共题库。保存专题完整快照、每次开始/结束时间、答案与对错。逐题提交即持久化；刷新将未完成挑战标记为中断，不丢弃已答内容。

历史最佳正确率等于本版本五题中曾经答对的数量除以5；本次成绩独立计算。失败重试不覆盖旧记录或撤销通关。已做过的专题进入详情；未做过的专题直接开始。支持导出个人JSON备份和校验后合并导入；冲突、损坏、容量不足或其他标签页改写时拒绝覆盖。

更多挑战读取资料库现有标签：不同维度AND、同维度OR、民族单选，前后端均校验。选标签后先查档案，不根据标签名自由编造。重复标签可进入旧专题，也可明确生成独立新专题；新UUID对应独立题目与历史，刷新不重新生成。清除站点数据会丢失个人记录，不提供跨浏览器同步。旧五关原型没有持久化历史，不伪造迁移。

## 模型接入与校验

提供方为硅基流动，实际验证账户模型列表支持 deepseek-ai/DeepSeek-V4-Flash。模型列表成功不能证明账户有余额。先前生成返回HTTP402、code30001、余额不足；充值后两个模块已真实生成。初版质量修订使用新的证据片段提示生成版本2，不改写旧题。

每道题关联真实档案ID、修订号与原文证据。模型引用证据编号，服务器回填真实原文，避免模型自行改写。恰好五题、唯一ID/题干/知识点、有效四选一答案、来源属于检索结果、引用确为原文、答案存在于原文、中文档案名匹配、中文可读选项均须通过。技术文件名、内部编号、帧率等考点被拒绝。校验不能完整证明所有语义都无歧义，仍支持明确修订。

无结果或有效片段不足时不调用模型；401/402/403/429、超时、非JSON、数量错误、无效来源均明确报错，不保存不完整专题。不自动反复重试扣费。AI原始输出不会直接发布。来源由宿主跳到 #/record/:id，ID使用encodeURIComponent；不存在的档案不展示入口。

本机 .env 配置：
DEEPSEEK_API_KEY
DEEPSEEK_BASE_URL=https://api.siliconflow.cn/v1
DEEPSEEK_MODEL=deepseek-ai/DeepSeek-V4-Flash
QUIZ_AI_TIMEOUT_MS=60000
QUIZ_ADMIN_TOKEN

真实Key只在服务端用于Authorization，不进入浏览器、HTML、日志或提交。QUIZ_ADMIN_TOKEN 是独立的固定题库管理凭据，不是模型Key，临时输入管理界面，不持久化。

package.json 的 dev/start 使用 --env-file-if-exists=.env；本次验证 Node v24.22.1。终端没有Node时可使用Codex内置运行时绝对路径。当前4320预览继续使用原临时档案数据，正式题库单独存项目data/quiz-banks.json，不重置档案库。

API：
- GET /api/quiz/bootstrap：固定题库、真实标签、可用档案与配置状态，无密钥。
- POST /api/quiz/generate：动态专题，不保存服务器个人进度。
- POST /api/quiz/admin/generate：管理令牌；默认读现有版本，revise新增版本。
- GET /api/quiz/admin/drafts：管理令牌读取题库版本列表。
- POST /api/quiz/admin/check-model：查询模型，不生成题目。
- 旧草稿发布兼容入口保留；当前流程不依赖人工审核，仍执行来源和版本校验。

## 构建与验证边界

公开构建白名单包含新模块与最新固定题库，读取固定题库后可离线于模型服务答题。当前Cloudflare公开站保持只读，尚未部署动态出题服务；公开站明确提示该限制，不打包本机.env或Key。已有题库与个人学习记录功能仍可用，不声称云端AI已经部署。

自动测试覆盖真实专题筛选、标签AND/OR、民族单选、来源证据、质量拦截、API错误不保存、版本冻结、逐题最佳并集、通关永久、跨版本历史、存储损坏/冲突、HTTP权限及隔离构建。

隔离浏览器流程验证两专题答题、失败重试、重复专题、刷新恢复和销毁。真实页面已核对新版题干、四个中文选项和显式切换版本。未测试的浏览器引擎或操作系统不标记通过。完整测试中的两个既有三维测试仍因缺少Git LFS实际模型而失败，准确计数以交付报告为准。
