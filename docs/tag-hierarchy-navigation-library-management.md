# Tag层级构建 / 导航交互 / 共创管理资料库开发

- 文档日期：2026-11-13。
- 说明对象：本次新增的资料组织体系、资料库阅读界面、地图交互、专题资料库管理和正式工程接入。
- 当前状态：已接入本地正式工程，公开只读构建已更新；本次工作不包含线上部署。
- 正式入口：`http://127.0.0.1:4318/`，启动命令为 `npm start`。
- 本文按当前实现整理，集中说明本次开发内容、交互行为与实现边界。

## 一、地域民族／专题／资料条目／标签树体系

### 1.1 体系目标

- 以游戏资产、图片和相关文件作为资料库的主体。
- 用地域、民族和专题提供不同的浏览入口，连接文化介绍与实际资料。
- 用分类标签树描述物品类别、形制、外观细节和资料类型，支持资料筛选与编辑。
- 将阅读页面与编辑页面接入同一份数据状态，减少重复维护和显示不一致。
- 为服装、饰品之外的布艺、工具、玩具等资料保留统一组织方式。

### 1.2 各类对象及其职责

| 对象 | 主要记录内容 | 当前作用 |
| --- | --- | --- |
| 地域词条 | 地域名称、地理介绍、地方服饰或工艺线索、关联民族、关联专题 | 地图导航及地域阅读入口 |
| 民族词条 | 民族概况、文化生活、传统服饰、主要分布地域、参考来源 | 民族阅读及地域关联入口 |
| 专题 | 专题名称、简介、关联地域、关联民族、资料归属及可用标签树 | 组织一组相关资料的中间层 |
| 资料条目 | 名称、所属专题、标签、来源、说明、套装及部件关系 | 可编辑、可引用的基本资料实体 |
| 文件／媒体 | 模型、图片、图纸、视频、配方、节点样式等 | 资料条目的实际展示及下载内容 |
| 标签节点 | 稳定标识、名称、父节点、所属维度或专题 | 分类、筛选和向父级汇总 |

组织关系可概括为：

```text
地域词条 ── 关联 ── 专题 ── 收录 ── 资料条目 ── 包含 ── 文件／媒体
民族词条 ── 关联 ── 专题                  │
    │                                  ├── 使用标签树中的节点
    └── 分布关系 ── 地域词条              └── 可关联套装及部件
```

地域、民族与标签提供不同维度的关联。专题负责集中组织资料，条目和文件承担具体内容。

### 1.3 地域与民族词条

- 中国地域按34个省级区域组织，使用与地图一致的地域代码。
- 民族按56个民族建立稳定入口，标识为 `ethnic-01` 至 `ethnic-56`。
- 民族条目保存分布地域，省级页面从同一份分布关系反向生成民族入口。
- 当前整理了189条民族与省级地域关系，保留主要聚居、散居等来源中的差别。
- 汉族在民族索引中单列，页面采用较简洁的概述；其他55个民族继续以目录方式浏览。
- 中国入口提供省级目录，国内浏览以具体省级词条为重点；国外目前保留较粗的入口。
- 每个省级词条包含地理概述和地方服饰／工艺线索；民族词条包含概况、文化生活、传统服饰与地域分布。

### 1.4 专题作为中间组织层

- 专题将一组有共同文化或制作背景的资料集中在一起。
- 专题维护地域与民族关联，上传资料时继承当前专题上下文。
- 省级页面和民族页面按专题关联信息，显示相关专题的介绍及代表资料预览。
- 专题阅读页集中展示简介、关联地域、关联民族、标签筛选和资料卡片。
- 当前初始专题包括摩梭人服饰与手作、乌克兰服饰、游戏基础资产，另设待整理资料分组。
- 当前编辑界面按一个主要专题归属管理条目，尚未提供任意多专题归属的完整编辑流程。

专题中的地域与民族信息承担文化背景关联。资料的拍摄地、制作地等具体信息可在原始档案及来源字段中另行记录。

### 1.5 摩梭专题的具体落地

- 以现有摩梭套装、头饰、上衣、长裙、关联鞋垫及补充影像作为试点，共6条初始资料。
- 地域关联采用云南、四川，连接滇川泸沽湖文化背景。
- 民族关联保留对应地域范围：云南摩梭人关联纳西族，四川左所摩梭人关联蒙古族。
- 摩梭人作为文化专题入口，连接民族词条和省级地域词条。
- 套装、部件、同图手作及补充影像保留不同资料关系，资料条目分别管理。
- 文化与地域关系的参考来源位于专题页末尾，物品名称及可见特征依据项目现有档案和素材。

### 1.6 资料条目与文件的关系

- 一条资料对应一个稳定标识，可同时拥有多个媒体或制作文件。
- 套装和部件沿现有 `record_type`、`parent_id`、`collection_id` 组织。
- 具体套装、头饰、上衣、鞋垫和补充影像均为资料实体。
- 同一条资料可提供模型图、三维模型、参考影像和UV图纸等不同查看形式。
- 文件层记录文件名、类型、路径、大小及顺序等信息。
- 用户新增的资料保存为正式条目，并将文件写入项目媒体目录。

### 1.7 标签树的维度

| 标签维度／树 | 当前示例 | 主要用途 |
| --- | --- | --- |
| 服装 | 上衣、裙装、鞋履 | 描述服装类别及形制 |
| 饰品 | 头饰、珠饰、腰饰 | 描述饰品类别及形制 |
| 布艺 | 鞋垫、面料、流苏 | 描述布艺相关物品 |
| 工具 | 制作工具、测量工具、生活工具 | 接入工具类资产 |
| 玩具 | 玩偶、游戏用具 | 接入玩具类资产 |
| 外观与结构 | 珠串、花纹、褶裥 | 描述跨物品使用的细节 |
| 资料类型 | 套装、补充影像 | 描述资料的组织或内容类型 |

- 标签树按父子关系表达分类层级，多棵树组成标签森林。
- 当前只允许选择末端子节点给资料打标签，父节点用于表达分类和汇总状态。
- 保存末端节点时自动补齐祖先标识，用于分类汇总和上级查询。
- 标签采用稳定标识，重命名保留原有引用。
- 具体物件和图片文件留在资料条目中，标签树中保留类别名称。
- 专题可新增自定义树和子节点，共享的基础分类继续复用。

### 1.8 自动类型与兼容处理

- 已有套装根据 `record_type=ensemble` 补齐“套装”类型标签。
- 现有摩梭补充影像依据其资料集合识别为“补充影像”；新资料也可通过对应末端节点归类。
- 旧数据中的标准根名称“组合形式”迁移为“资料类型”，保留稳定标识。
- 读取旧编辑记录时清理曾混入标签列表的具体条目引用。
- 固有类型补齐后，资料卡片和专题筛选使用同一结果。

### 1.9 标签筛选逻辑

- 专题默认展示全部资料，筛选项直接展开，避免将小专题做成多步查询表单。
- 同一标签树内选择一个末端标签，其他树可继续选择标签。
- 不同树之间按交集筛选。
- 其他候选项根据当前条件计算可用数量，仅显示有结果的选项。
- 再次点选已选项可取消，支持恢复全部资料。
- 正式阅读页将筛选条件写入站内路由，便于刷新及前后历史切换。
- 共创预览复用同一筛选组件，在当前面板中更新结果。

### 1.10 知识资料与来源组织

- 当前34个地域词条和56个民族词条，共保存183条来源记录、181个不同来源网址。
- 民族内容主要采用国家民委资料，服饰和工艺补充使用非遗、政府、博物馆及研究资料；省级地理概述使用公开百科等资料。
- 数据保存来源列表、逐字段来源映射、核验方式和范围说明。
- 当前来源记录中178条标记为完整正文核对，5条标记为检索正文核对，保留核验差异。
- 正文采用简要介绍，来源、注释集中在页尾折叠区，减少阅读区零散的外链按钮。
- 来源介绍与具体游戏资产的视觉观察分别记录，后续可继续补充实物、年代及工艺考证。

## 二、资料库阅读与地图交互

### 2.1 资料库主界面

- 沿用正式项目的品牌、导航和纸色、青绿、细线、宋体标题等视觉元素。
- 资料库主体展示真实项目素材，包括套装、部件、影像、图纸、配方和节点样式。
- 套装采用整体展示与部件展示相结合的布局。
- 按资料形式提供筛选入口，详情页保留文件与来源信息。
- 本次接入的初始素材包括30条档案、27个模型展示入口、8个UV图纸入口、2种配方及6种节点样式。
- 当前本地有17个可加载GLB，运行时检测实际文件可用性。

### 2.2 地图作为阅读导航

- 左侧设置中国省级地域地图，并提供地域及民族搜索目录。
- 点击省级区域进入相应词条。
- 鼠标悬停时区域高亮、上浮；离开后恢复。
- 当前地域或相关地域通过统一色彩表达选中状态。
- 地图使用SVG与原生交互实现，提供类似地图图表组件的缩放和漫游体验。

### 2.3 缩放、拖拽与复位

- 滚轮按鼠标所在位置缩放，保持当前关注位置相对稳定。
- 拖拽移动地图，拖拽完成后抑制误点击。
- 复位按钮使用平滑动画返回初始视图。
- 控件只保留复位，缩放主要通过滚轮完成。
- 提供键盘方向移动和Home复位操作，并响应系统减少动态效果设置。

### 2.4 地图文字与小面积地域

- 文字使用独立的屏幕坐标层，字号保持稳定。
- 根据缩放、地域形状及文字可用空间决定显示和隐藏。
- 文字避让与显示／隐藏的稳定机制减少缩放临界位置闪动。
- 北京、天津、上海、香港、澳门采用固定地理位置的圆点入口，扩大可操作范围。
- 圆点随地图移动，离开视野后隐藏。
- 对相近圆点按真实锚点距离选择，改善港澳等微小区域的点击可靠性。

### 2.5 悬停稳定性处理

- 视觉省域与鼠标命中轮廓分别处理。
- 上浮动画改变显示位置，命中区域保持稳定，减少边缘反复触发悬停的闪动。
- 对宁夏等狭长区域，在文字显示判定中保留空间余量和短暂稳定时间。
- 地图尺寸变化后重新布局标签。

### 2.6 民族与专题地图联动

- 打开民族词条时地图复位，其分布关系所覆盖的地域集体高亮、上浮。
- 打开专题时地图根据专题关联地域展示背景范围。
- 修改专题地域后，专题地图与对应省级词条中的专题预览随共享状态更新。
- 省页提供相近地域推荐，并结合已有分布关系提供民族推荐。
- 民族推荐依据已整理的地域关系生成，属于浏览辅助信息。

### 2.7 省页与民族页的渐进展示

- 在省页、民族页中嵌入相关专题的简要介绍和最多3条代表资料预览。
- 用户可先了解专题内容，再通过统一的“展开专题”入口继续浏览。
- 预览中的图片与资料名称保持静态展示，避免省页直接散落多个资料跳转。
- 专题页再集中提供完整资料列表及筛选。

### 2.8 页面目录与前后导航

- 阅读页右侧按实际章节生成轻量目录。
- 目录随滚动保持可用，并高亮当前阅读章节。
- 点击目录平滑定位，来源入口可展开页尾参考资料。
- 窄屏将目录收为正文上方的可展开控件。
- 正文左上方提供后退、前进按钮，用于站内页面及路由筛选状态切换。
- 共创编辑页移除阅读目录，将空间留给资料树和编辑内容。

### 2.9 资料详情与三维预览

- 模型文件可用时，打开资料页自动加载三维预览。
- 支持旋转、缩放及模型已具备的动作切换；静态模型也可查看。
- 可在三维模型、参考影像和图纸之间切换。
- 切换查看方式或离开页面时清理动画及WebGL资源。
- 加载失败回退图片并提供重试入口。
- 对仍为Git LFS指针的模型保留图片或图纸展示。

### 2.10 媒体预览与排序

- 有独立模型图的资产，编辑预览以资产图和该条目新增媒体为主。
- 原始来源照片及概念参考图保留在阅读页参考影像中。
- 纯影像资料按图组展示，支持上一张、下一张和缩略图切换。
- 支持拖动缩略图、箭头前后移动以调整顺序。
- 媒体顺序使用稳定标识保存，刷新后恢复；首图更新同步到资料卡片。
- 图片、SVG保持比例显示，视频使用播放器，文档及配方等使用文件信息展示。
- 预览框限制媒体尺寸和溢出，标题及说明独立排版。

## 三、参与共创与资料库管理交互

### 3.1 共创首页

- `#/contribute` 作为共创入口首页。
- 提供资料库管理入口，进入 `#/contribute/library`。
- 提供题库编辑入口，连接现有 `#/questions`；本次只接入入口。
- 提供GitHub项目入口，使用项目远端仓库地址，新标签页打开。
- 原首页、指南、答题练习和制作工具保留。

### 3.2 资料库管理总体布局

- 管理界面采用资料树与内容面板并列布局，移除地图。
- 左侧展示专题、套装、资料与部件层级，提供名称或编号搜索。
- 默认打开第一个专题的资料预览。
- 点击专题名称显示完整资料预览；点击“编辑专题”进入专题信息及标签树编辑。
- 点击具体资料进入其编辑界面。
- 侧栏仅负责定位，具体添加操作放在对应标签节点的菜单中。

### 3.3 专题预览

- 展示专题名称、简介、关联地域、关联民族及全部资料卡片。
- 使用与正式阅读页共用的标签筛选逻辑。
- 地域、民族、卡片、资料名称及来源保持纯展示，预览面板不提供外跳入口。
- 点击筛选项只更新面板内容，保持当前共创上下文。

### 3.4 专题信息编辑

- 支持新建专题，以及编辑专题名称和简介。
- 在专题内部维护关联地域和关联民族，列表提供搜索和多选。
- 上传资料时继承当前专题关联信息。
- 编辑后自动保存，移除手动“保存专题”按钮和独立草稿操作。
- 专题编辑面板下直接展开可编辑标签树。

### 3.5 标签森林排版

- 按节点和连线呈现分类关系，多个根节点形成森林。
- 根节点和子节点方框按字段长度收缩。
- 根据实际内容宽度并排排布，有空间的树放在同一行，空间不足时换行。
- 根节点长名称可按可用宽度换行，避免固定宽度造成大面积空白。
- 父子节点使用平滑曲线连接。
- 根据真实节点位置计算连线；窗口、节点尺寸和字体变化后重绘。
- 所有子节点默认展开。

### 3.6 节点浏览与右键菜单

| 操作 | 当前行为 |
| --- | --- |
| 左键点击节点 | 高亮节点并展示其关联资料 |
| 点击关联资料 | 进入该资料的编辑界面 |
| 右键点击节点 | 弹出节点操作菜单 |
| 点击“⋯” | 打开同一菜单，适配触屏使用 |
| 菜单“添加资料” | 在允许的末端子节点下打开上传弹窗 |
| 菜单“新增子节点” | 输入节点名称并创建 |
| 菜单“重命名” | 编辑名称并自动保存 |
| 菜单“删除空节点” | 对符合规则的空末端子节点执行删除 |

菜单限制在视口范围内，支持方向键移动和Escape关闭。

### 3.7 节点选择和删除规则

- 根节点和中间节点用于组织分类，展示其后代的选中情况。
- 给资料打标签时只点击末端子节点，选中后以青绿高亮表示。
- 根节点或中间节点不直接承接“添加资料”。
- 删除只允许无关联资料的末端子节点。
- 已关联资料的节点显示锁定状态，执行删除时重新检查关联。
- 前端菜单及正式后端均对相关约束进行检查。

### 3.8 定向添加资料

- 在末端标签节点上选择“添加资料”，直接打开弹窗。
- 弹窗保留上传、预览、命名及补充来源信息。
- 所属专题与标签由当前操作位置确定，弹窗不重复要求选择。
- 新条目保存时推导祖先标签，并进入资料库侧栏。
- 关闭弹窗后返回原专题编辑上下文。

### 3.9 文件上传与补充信息

- 支持选择文件和拖放文件。
- 当前接受图片、SVG、GLB、图纸／PDF、视频及JSON／TRES等配方文件。
- 单个文件上限50 MB。
- 对支持的文件进行名称、类型和内容校验。
- 可填写资料名称、作者或机构、来源网址和说明。
- 新增文件使用随机文件名保存，保留用户文件名称等媒体元数据。
- 编辑预览与阅读展示共用已保存的文件和顺序信息。

### 3.10 自动保存及状态反馈

- 文本修改采用约400毫秒防抖保存。
- 切换编辑位置、关闭上传弹窗或离开管理页面前提交待保存内容。
- 标签选择和媒体顺序调整沿用同一保存链路。
- 元数据和文件采用有序保存流程，减少较早请求覆盖较新内容的情况。
- 界面显示保存中、已保存到项目或保存失败状态。
- 保存失败时保留当前输入；后续编辑可继续尝试保存。
- 当前界面已移除手动保存、草稿列表及“恢复草稿”按钮。

### 3.11 编辑与阅读即时响应

- 编辑、阅读和预览共用资料库读模型。
- 修改专题名称、简介和地域／民族关联后，相关阅读页面重新计算显示内容。
- 移除某地域关联后，相应省页移除该专题预览；新增关联后添加预览。
- 标签改名保留标识，资料上的名称、筛选项及数量使用最新状态。
- 条目名称、说明、类型标签和媒体顺序更新后，资料卡片和详情同步读取。
- 同站点标签页通过通知重新加载已保存状态。
- 阅读更新尽量保持当前滚动位置；编辑更新避免反复重建正在填写的表单。

## 四、正式工程接入与实现结构

### 4.1 接入方式

- 模块放入 `public/library/`，直接嵌入正式应用。
- 原资料库与共创路由接入新版控制器。
- 保留 `#/assets`、`#/record/...` 等兼容入口。
- 正式数据来源改为项目后端；演示的静态种子快照不参与正式运行。
- PR仅交付完整正式工程，预览工程和阶段笔记保存在本地归档中，不随PR提交。

### 4.2 数据持久化

- 正式档案保存在 `data/records.json`。
- 专题、标签树、关联、媒体顺序和文件索引保存到其中的 `library` 字段。
- 条目名称、说明、来源和可确定的主类别同步更新正式记录。
- 沿用先写临时文件、再替换目标文件的原子保存机制。
- 上传文件写入 `public/media/`。
- 重启后从项目数据恢复，浏览器不再是正式数据的唯一保存位置。

### 4.3 主要模块
